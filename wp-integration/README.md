# Агростандарт — WordPress-паттерны новой структуры сайта

Тот же дизайн и тексты, что и в статичной версии (`site/`), только упакованы
как Gutenberg-паттерны для вставки в любой WordPress поверх любой темы.

## Что внутри

```
agrostandart-patterns/
  agrostandart-patterns.php     — плагин: подключает шрифты/стили/скрипт, регистрирует паттерны
  assets/
    css/agrostandart-design-system.css  — вся дизайн-система, целиком в .as-agrostandart
    js/site.js                          — мобильное меню, форма заявки, год в подвале
    images/web/                         — фото (оптимизированные, ~7 МБ)
    docs/                               — готовые PDF-каталоги (дойное стадо, откорм КРС)
  patterns/
    00-header.html …  08-politika-konfidencialnosti.html — 9 паттернов
```

## Установка

1. Скопируйте `agrostandart-patterns/` в `wp-content/plugins/` и активируйте
   плагин («Агростандарт — блок-паттерны») **или** в `wp-content/mu-plugins/`
   — включится сам, без активации.
2. В редакторе страницы → «+» → вкладка **Паттерны** → категория
   **Агростандарт**. Там 9 паттернов.

## Как собрать каждую страницу

Каждая реальная страница сайта = **Шапка** + своё тело + **Подвал**, вставленные
друг за другом на одной странице WP, в этом порядке. Создайте страницы со
следующими URL (slug) — на них ссылаются паттерны через абсолютные пути:

| URL (slug страницы в WP)            | Какой паттерн вставить телом              |
|--------------------------------------|--------------------------------------------|
| `/` (главная)                        | Агростандарт — Главная (тело страницы)      |
| `/produktsiya/krs-doynoe/`           | Агростандарт — Дойное стадо                 |
| `/produktsiya/krs-otkorm/`           | Агростандарт — Откорм КРС                   |
| `/produktsiya/svini/`                | Агростандарт — Свиньи                       |
| `/produktsiya/indeyka/`              | Агростандарт — Индейка                      |
| `/produktsiya/bvmkk-61-1s-k/`        | Агростандарт — Карточка продукта БВМКК-61-1С-к |
| `/politika-konfidencialnosti/`       | Агростандарт — Политика конфиденциальности  |

`/produktsiya/` — родительская страница-хаб для четырёх направлений и карточки
продукта (Настройки страницы → Родительская страница), чтобы адреса совпали.

Разделы «Технолог», «Производство», «Каталоги», «Задачи хозяйства», «Дилерам»,
«Заявка на расчёт», «Контакты» и «О компании» — это **якоря внутри главной**
(`/#tech`, `/#quality`, `/#dl`, `/#tasks`, `/#dealers`, `/#raschet`,
`/#contacts`), а не отдельные страницы — так же, как в утверждённом макете.
Отдельных WP-страниц для них создавать не нужно.

## Что стоит донастроить перед публикацией

- **Форма заявки** (в теле главной) сейчас отправляет данные через `mailto:` —
  открывает почтовый клиент посетителя. Если на сайте уже есть плагин форм
  (Contact Form 7, WPForms и т. п.), поля `input/select/textarea` внутри
  `.form` можно заменить на шорткод формы, сохранив обёртку и классы ради
  того же внешнего вида.
- **Мобильное меню** — гамбургер-кнопка есть в паттерне «Шапка», работает
  через `assets/js/site.js`. Если тема WordPress уже подключает jQuery/другой
  скрипт с похожими классами — проверьте, что конфликтов нет (здесь чистый
  JS без зависимостей, id с префиксом `as-`).
- **Политика обработки персональных данных** — на странице сейчас честная
  заглушка: реальный юридический текст должен подготовить юрист заказчика.
- Логотип вставлен как inline SVG (настоящий файл из
  `АГРОСТАНДАРТ_ЛОГОТИП/для веб/горизонтальный/svg/`) — отдельно загружать
  в Медиатеку не нужно.

## Мобильная адаптивность

Брейкпоинты — как в статичной версии, проверены на ширинах 375–1920px:
гамбургер-меню и липкая нижняя панель «Позвонить / Расчёт» — от 640px и уже.
